Operating mode

Monitoring-only mode is configured on the Raspberry Pi with BASELINE_MODE. Relay requests are enforced by the device agent. An authorized RFID card must be scanned twice within 5 seconds to clear a trip latch; reset leaves all outputs OFF.

Support

Operating notes

  1. Confirm the sensor diagnostics report current readings and match the physical circuit.
  2. Set each channel limit in watts (W); the system cap is also in watts.
  3. Use the channel switches to request power. The Pi rejects ON requests on sensor or configuration failure.
  4. Verify relay polarity and wiring on a disconnected test load before connecting appliances.
